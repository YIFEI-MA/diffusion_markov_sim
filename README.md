# Stock Market Simulation/Prediction with Markov Process  
  
## Prerequisites
Python 3.7, 3.8 , or 3.9 is required. To install Numpy Scipy NetworkX and NDlib with pip:  
```shell  
pip install numpy scipy matplotlib pandas 
pip install sklearn  
pip install networkX[default]  
pip install ndlib  
```

## Usage
To run  simulation in Linux/macOS:  
Make sure you are under src folder, then run following.  
```shell
/your_python_path/with_prerequisites_installed/python simulation.py
```

To save output for spreadsheet software:
```shell
/your_python_path/with_prerequisites_installed/python simulation.py > result.tsv
```
Figures can be saved on the interactive matplotlib GUI.
